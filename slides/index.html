GIT06

FIRST PUSH

Connect the project to GitHub.

Empty Public repo. No README. Second terminal if npm run dev is still running.

git init
git branch -M main
git add .
git commit -m "Create my portfolio"
git remote add origin https://github.com/YOUR-USER/YOUR-REPO.git
git push -u origin main

Checkpoint: your files appear on github.com.

GIT07

SAFE READS

Start with git status.

  1. git statusWhat changed? Which branch?
  2. git diffWhat did I edit?
  3. git remote -vWhere does push go?

Which command do you run first when something looks wrong?

REVIEW13

CHECK LOCALLY

Before the pull request.

  1. Diff shows only the intended files

REVIEW14

GITHUB

Open the pull request. Read Files changed.

  1. Compare & pull request
  2. base: main · compare: your branch
  3. Files changed · match the issue?
  4. Merge when it is correct

Name one reason you would not merge yet.

DEPLOY15

LIVE SITE

Merge to main. Open the URL.

  1. Settings → Pages · Source = GitHub Actions
  2. Actions · wait for green (Re-run if needed)
  3. Visit site · test the real URL

Feature branches do not publish this starter.

HELP16

TROUBLESHOOTING

Read the error. Fix one thing.

  • Auth / password — browser sign-in or PAT, not your GitHub password
  • Actions failed — open the log, fix the first real error
  • 404 on the site — Pages source set? Latest run green? Full project URL?
  • Change missing — merged to main? Hard refresh?

What exact error would you show a helper?
