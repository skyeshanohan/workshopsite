Using Copilot

Prompts to try in Copilot

First, understand the project

First, ask Copilot to explain the project. Then decide what to change.

Explain this project structure and how the page, styles, and resume data fit together. Don't change any files yet. List the safest files for me to edit first.

Make one focused change

Tell Copilot what you want to change and what it should leave alone.

On the current portfolio, improve the visual hierarchy of the project cards. Keep the existing framework and layout. Make the change responsive, explain which files you changed, and don't add dependencies.

Ask for a review

Ask Copilot to review the changes, then check them yourself.

Review the changes you just made. Identify possible layout regressions, accessibility issues, broken links, or assumptions. Do not modify files until you explain the findings.

Start by reading the error

Paste the error message and ask what to check first.

Here is the exact error message: [paste error]. Explain the most likely cause, how I can verify it, and the smallest safe fix. Do not rewrite unrelated files.
AI safety: Don't paste passwords, API tokens, private keys, or personal information you don't want to publish. Read every proposed change and verify it before committing.
